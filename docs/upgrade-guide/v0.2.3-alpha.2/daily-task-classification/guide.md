# Use daily task classification

English | [中文](guide.zh.md)

## Change

The Daily tasks board moves tag management to Settings. The context menu replaces Breakdown and Standardize with model-assisted Classify. Adding a task keeps the chosen column.

## Migration

1. Open Daily tasks → Settings → Tag management to create and edit tags. Double-click a tag on the board to open its editor.
2. In Settings → Model, choose the default DSH route or configure JEV. Open a task's context menu, choose Classify, and check which matching tags were added.
